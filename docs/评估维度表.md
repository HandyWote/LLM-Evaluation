### 表 3：评估方法分类

*注：针对每篇论文，标记 Yes 或 No。*

| 列名 | 定义 | 包含条件 (标 Yes) | 排除条件 (标 No) | 核心判断规则 |
| :--- | :--- | :--- | :--- | :--- |
| **Eval_Human_Experts** | 领域专家进行的评估 | 治疗师、临床医生、领域专家、受过训练的标注员 | 众包工人、无专业知识的学生、LLM评估 | 评估者具备与任务相关的**领域专业知识**。 |
| **Eval_Lay_Users** | 非专家/普通用户评估 | MTurk/Prolific众包工人、普通用户、未提及专业背景的"参与者" | 领域专家、受过训练的标注员 | 参与者是**没有领域专业知识的普通用户**。 |
| **Eval_User_Study** | 结构化实验 | 用户与系统发生**交互**，有明确任务、协议或实验设计 | 简单的打分任务（无交互）、静态输出评估 | 参与者在实验环境中**主动与系统发生了交互**。 |
| **Eval_LLM_Judge** | 大模型作为裁判 | 使用 GPT-4/Claude 等进行打分、比较、排序 | 提取向量相似度、特征提取、计算指标 | LLM 被提示去**评估、打分或比较**输出结果。 |
| **Eval_Automatic** | 算法/数学自动计算 | BLEU, ROUGE, Accuracy, F1, Cosine相似度, 任务成功率 | LLM打分、人类打分 | 通过**公式或算法计算**得出，无人类或LLM主观判断。 |

### 表 4：评估核心维度

*注：根据论文明确评估的内容，标记 Yes 或 No。*

| 列名 | 定义 | 关键词 | 排除项 | 核心判断规则 |
| :--- | :--- | :--- | :--- | :--- |
| **Safety** (安全性) | 是否避免有害/偏见输出 | Safety, harmful, bias, ethical | 有用性 | 评估有害性或伦理问题。 |
| **Realism** (真实性) | 输出是否像人类或自然 | Realistic, human-like, natural, believable | 正确性、任务成功率 | 评估输出是否**类似于人类的行为或语言**。 |
| **Consistency** (一致性) | 跨轮次行为是否稳定 | Consistency, persona stability, drift, trait alignment | 单轮质量 | 评估在**多轮交互中的稳定性**。 |
| **Fidelity** (保真度) | 是否符合预设角色/目标 | Alignment, fidelity, adherence, match to persona | 一般的真实性 | 评估输出与**预设身份或模型匹配**的程度。 |
| **Human Learning / Outcomes** (人类学习) | 是否带来人类进步/改变 | Learning, skill improvement, confidence, outcomes | 仅评估感知 | 测量人类在知识、技能或行为上的**实质变化**。 |
| **Utility** (实用性) | 对任务是否有用/有效 | Helpful, useful, effective, performance | 仅评估真实性 | 评估系统的**有用性或有效性**。 |
| **Emotional Plausibility** (情绪合理性) | 情绪反应是否真实/恰当 | Empathy, emotion, affect, emotional realism | 事实正确性 | 评估情绪行为或共情能力。 |

### 表 5：交互层级

*注：衡量评估包含了多少对话上下文。单轮为表面质量，多轮测行为。可选值以 Excel 为准。*

| 可选值 | 定义 | 关键特征 | 解释与意义 |
| :--- | :--- | :--- | :--- |
| **Single-turn** (单轮) | 一次只评估一个回复，无历史记录 | 无交互、无记忆、无动态 | 仅测量表面合理性。 |
| **Short Multi-turn** (短多轮) | 包含简短交流 (2-5轮) | 有一定上下文，交互深度有限 | 略好于单轮，但仍然较浅。 |
| **Extended Dialogue** (长对话) | 基于较长对话的评估（通常 6+ 轮，经验性划分） | 时间动态、一致性重要、策略重要 | 可以评估行为的有效性。 |
| **Longitudinal** (纵向) | 跨越多个会话/较长时间的评估 | 长期一致性、发展、跨会话记忆 | 最接近真实的心理咨询场景。 |

### 表 6：提示词披露度

*注：评估实验的可复现性。*

| 可选值 | 定义 | 常见证据 | 解释与意义 |
| :--- | :--- | :--- | :--- |
| **Full Disclosure** (完全披露) | 清晰提供了所有必要提示词 | 论文正文、附录或GitHub中给出了系统提示词、用户模板、评估提示词 | 原则上**可复现**。 |
| **Partial Disclosure** (部分披露) | 展示了部分提示词，不足以复现 | 仅给1-2个例子，或只用文字描述（如"让模型扮演治疗师"），缺失评估提示词 | 知道思路，但**无法完全复制**。 |
| **No Disclosure** (未披露) | 没有可用的提示词信息 | 仅说"使用GPT-4生成/评估"，无任何细节 | **不可复现**。 |

### 表 7：理论支撑度

*注：评估标准是否与公认的心理学/咨询/社会科学理论挂钩。不要仅因为提到了心理健康就打分。*

| 可选值 | 定义 | 判断依据与示例 |
| :--- | :--- | :--- |
| **Strong** (强) | 明确使用公认理论来**定义或测量** | 使用了CBT概念、MI编码、经过验证的临床量表、明确的共情维度定义。*例："使用经过验证的量表评估共情"* |
| **Weak** (弱) | 提及了概念但**未在评估中实际操作化** | 引言中提到CBT/共情，但评估只是让用户打分(1-5 helpfulness)；使用"共情"词汇但无理论评分标准。 |
| **None** (无) | 没有真正的理论支撑 | 仅评估流畅度、偏好、真实性；LLM打分没有基于理论的评分标准；把共情当成一个直觉标签。 |

**对应 Excel 列**：Theory_Grounding（col 29）

### 表 8：理论操作化程度

*注：理论是否被用于定义评估标准或指标，而不仅仅是提及。与表 7 互补：表 7 判断"有没有理论"，本表判断"理论用了多深"。*

| 可选值 | 定义 | 判断依据与示例 |
| :--- | :--- | :--- |
| **Strong** | 评估标准明确源于理论 | 评估rubric直接来自CBT量表；共情评分维度对应临床定义 |
| **Partial** | 理论被提及并部分操作化 | 提到了CBT框架，但只用了其中1-2个维度作为评估项 |
| **Mentioned** | 理论仅被提及，未操作化 | 引言提到"基于CBT"，但评估指标与理论无关 |
| **None** | 没有使用任何理论 | 仅用BLEU/ROUGE等自动指标，或LLM自由打分 |

**对应 Excel 列**：Theory_Operationalized（col 24）

### 表 9：行为评估深度

*注：论文对交互过程中行为变化的评估深度。核心分界线：有没有评估行为 → 有没有跨轮次汇总 → 有没有追踪变化趋势。*

| 可选值 | 判断标准 | 举例 |
| :--- | :--- | :--- |
| **Dynamic** | 分析了行为**如何随轮次变化** | "系统在第 3 轮后从支持转向挑战"、"共情水平逐轮下降" |
| **Pattern-level** | 统计了行为**出现的频率/模式**，但不关心变化 | "系统在 60% 的轮次使用了反映性倾听"、"高频出现共情语句" |
| **Static** | 对行为打了分，但**每轮独立评分**，不看轮次间关系 | "每轮回复的共情度 1-5 分，取平均" |
| **None** | **完全不涉及行为**，只看输出质量 | BLEU、ROUGE、流畅度打分、偏好排序 |

**对应 Excel 列**：Behavior_Eval_Depth（col 25）

### 表 13：评估质量标记

*注：逐项独立判断 Yes 或 No。*

| 列名 | 定义 | 标 Yes 条件 | 标 No 条件 |
| :--- | :--- | :--- | :--- |
| **Has_Rubric** | 是否提供了明确的评分标准/评分指引 | 有明确的评分量表、rubric、评分指南 | 仅说"让标注员打分"但无标准 |
| **LLM_Judge_Validated** | LLM裁判是否经过验证（与人类评估对比等） | 论文将LLM评分与人类评分做过任何形式的对比（包括相关性分析、一致性检验、均值差异检验、IAA表、甚至定性描述如"高度一致"）。只要做了对比就标Yes | 未使用LLM judge，或使用了LLM judge但完全没有与人类评分做任何对比。注意：仅报告人工编码者间信度（如Fleiss' kappa）不算，必须是LLM vs 人类的对比 |
| **Uses_Standard_Metrics** | 是否使用了标准/公认的评估指标（非自创） | 使用BLEU、ROUGE、BERTScore等公认指标 | 仅用自创指标且未与标准指标对比 |
| **Metric_Interpretable** | 评估指标的含义是否清晰可解释 | 分数含义明确，读者能理解好坏 | 自创指标无法理解分数意义 |
| **Comparable_To_Prior_Work** | 评估是否可与先前研究进行对比 | 使用了与先前工作相同的指标或数据集 | 自创数据集+自创指标+无基线 |
| **Has_Longitudinal_Eval** | 是否包含纵向/长期评估 | 跨多个会话或较长时间的评估 | 仅单次会话评估 |
| **Has_Robustness_Testing** | 是否在不同条件下进行了鲁棒性测试 | 在多种条件/数据集下测试 | 仅在理想条件下测试 |
| **Has_Failure_Analysis** | 是否分析了失败案例 | 有专门的失败案例分析章节或表格 | 未讨论系统失败情况 |
| **Sim_Behavior_Realistic** | 模拟行为是否真实（非过于顺从或简化） | 模拟用户有抵抗、情绪波动等真实行为 | 模拟用户过度配合、机械应答 |
| **Dataset_Available** | 数据集是否公开可用 | 提供了下载链接或公开仓库 | 未公开或需申请 |

### 表 14：评估缺陷清单

*注：为每篇论文挑选 1-2 个弱点，直接使用"结论短语"进行记录。*

| 缺陷类别 | 具体缺陷 | 为什么是问题 | 论文中可复制的**结论短语** |
| :--- | :--- | :--- | :--- |
| **人类评估问题** | 无评分标准 | 评估者标准不一，不可复现 | `lacks evaluation rubric` |
| | 样本量太小 | (<10人) 无法泛化，统计效力弱 | `limited sample size` |
| | 参与者专业性不明 | 不清楚评判是否可靠 | `participant expertise unclear` |
| | 仅靠主观打分 | 无客观证据，易生偏见 | `relies on subjective ratings only` |
| **LLM裁判问题** | LLM裁判未经验证 | 不清楚LLM打分是否靠谱 | `LLM judge not validated` |
| | 评估提示词未说明 | 不可复现，提示词影响极大 | `evaluation prompt not specified` |
| | LLM被视为真理 | 无人类对比，循环论证 | `assumes LLM evaluation is reliable` |
| **指标问题** | 仅用定制指标 | 无法与先前研究对比 | `uses custom metric without benchmark` |
| | 指标不可解释 | 看不懂分数的实际意义 | `metric lacks interpretability` |
| | 无法跨研究对比 | 自创数据集+自创指标+无基线 | `evaluation not comparable across studies` |
| **缺失评估维度** | 无真实人类结果 | 不清楚现实世界的价值 | `no real-world human outcomes evaluated` |
| | 无纵向评估 | 仅测单轮，忽略长期一致性 | `lacks long-term interaction evaluation` |
| | 无鲁棒性测试 | 仅在理想条件下测试 | `no evaluation under diverse conditions` |
| | 无失败案例分析 | 隐藏了系统局限性 | `lacks analysis of failure cases` |
| **生态效度问题** | 仅在模拟环境评估 | LLM互相对话，无真实用户 | `evaluated only in simulated settings` |
| | 模拟行为不真实 | 虚拟用户过于顺从 | `simulated behavior not realistic` |
| | 无真实世界部署 | 未走出实验室测试 | `not tested in real-world scenarios` |
| **透明度/复现** | 提示词未公开 | 无法复现系统设计 | `prompts not disclosed` |
| | 数据集不公开 | 无法复现实验结果 | `dataset not available` |
| | 评估流程不清晰 | 步骤描述模糊 | `evaluation procedure not clearly described` |
