Rethinking Evaluation for Repurposed Interactive LLM Systems

FIG 1

Dialogue gets longer; evaluation stays at the surface

Systems increasingly model dynamic user state, yet evaluation rarely follows beyond a single session. Each narrowing stage is an ingredient of behavioral validity — and each stage sheds papers.

Stages: all papers → evaluating extended dialogues (6+ turns) → system has an explicit dynamic user-state model → longitudinal (cross-session) evaluation. Percentages relative to N = 52.

FIG 2

Everyone evaluates — but with different judges

Evaluator types are not mutually exclusive. Most papers mix two or three evaluator types; only 15 (28.8%) combine human experts, LLM judges, and automatic metrics — and 3 papers use none of the three.

Left: set sizes (papers using each evaluator type). Right: each column is one combination — filled dots mark membership, bar height = number of papers in that combination.

Four gaps between practice and evidence

Each track pairs a common practice (teal) with its scarcer, more rigorous counterpart (rose). The distance between the dots is the gap this survey documents.

Local quality is measured; behavior is not

Left: how often each evaluation dimension is assessed at all. Right: the deepest level of behavioral evaluation each paper reaches (N = 52).
