## 模拟/角色建模

### focus_type: EvaluationFramework (confidence: 100)
**Evidence** (p.1): We introduce PersonaGym, the first dynamic evaluation framework for persona agents, and PersonaScore, a human-aligned automatic metric grounded in decision theory that enables comprehensive large-scale evaluation.

### simulation_target: Human Trainee (confidence: 60)
**Evidence** (p.1): Persona agents, which are LLM agents conditioned to act according to an assigned persona, enable contextually rich and user-aligned interactions across domains like education and healthcare.

### persona_model_depth: Surface Persona (confidence: 95)
**Evidence** (p.5): The agent LLM assumes the given persona using the system prompt, “You are [persona]. Your responses should closely mirror the knowledge and abilities of this persona.” as is done in (Gupta et al., 2024).

### uses_dynamic_state: NO (confidence: 95)
**Evidence** (p.2): PersonaGym operates through a three-stage evaluation pipeline. 1) Dynamic Environment Selection: An LLM reasoner selects relevant environments from a pool of 150 diverse domains based on the agent's assigned persona. 2) Persona-Task Generation: Task-specific questions are dynamically generated to probe the agent's persona-consistent behavior across each environment. 3) Agent Response Evaluation: The agent responds using a persona-specific system prompt.

### temporal_modeling_details:  (confidence: 95)
**Evidence** (N/A): No evidence of dynamic state or temporal modeling of the persona's internal state found in the paper. The 'dynamic' aspect of PersonaGym refers to dynamic environment selection and question generation, not to changes in the persona's state over time.

They are provided with a comprehensive rubric including task details, scoring criteria, agent-specific examples, persona descriptions, questions, and responses. Evaluators generate a score (1-5) with justification. The final score is the average across both models.

### eval_automatic: NO (confidence: 95)
**Evidence** (p.2): PersonaScore, a human-aligned automatic metric grounded in decision theory that enables comprehensive large-scale evaluation. ... PersonaScore evaluates these responses using expert-curated rubrics. ... To align PersonaScore with human preferences, we first generate exemplar responses at each rubric level using LLM reasoners, effectively calibrating the evaluators. Multiple state-of-the-art LLM evaluators then independently score the agent's responses, and we ensemble their judgments to ensure robustness and reduce individual model bias.
